# Frontend

Cài một lần tại **gốc dự án**: `npm run requirement`.

Sau đó mở terminal:

```sh
cd frontend
npm start
```

Mở **http://localhost:3000**. Backend phải chạy ở terminal khác.
Địa chỉ backend mặc định là `127.0.0.1:3001`; đổi `BACKEND_URL` trong `.env` nếu cần.
