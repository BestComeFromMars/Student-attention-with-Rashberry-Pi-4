# Model and code provenance

The active pipeline uses the following upstream projects. Package license texts remain in their installed distributions.

- Ultralytics YOLO11 and ByteTrack integration: https://github.com/ultralytics/ultralytics (AGPL-3.0 upstream; https://www.ultralytics.com/license).
- YOLO11 pretrained weights: https://github.com/ultralytics/assets/releases/tag/v8.3.0.
- ByteTrack paper implementation: https://github.com/ifzhang/ByteTrack.
- MediaPipe Face Landmarker and Hand Landmarker: https://github.com/google-ai-edge/mediapipe (Apache-2.0; see package and model terms).
- OpenCV: https://github.com/opencv/opencv (Apache-2.0 current releases).
- YuNet face detection model: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet. Model-specific MIT license: https://github.com/opencv/opencv_zoo/blob/main/models/face_detection_yunet/LICENSE. Copyright (c) 2020 Shiqi Yu.
- SCRFD five-keypoint detectors: https://github.com/deepinsight/insightface/tree/master/detection/scrfd. Production uses `det_10g.onnx` from the official `v0.7/buffalo_l.zip` for detailed verification and `det_500m.onnx` from `v0.7/buffalo_sc.zip` for bounded current-frame recovery of already verified faces. The 500M path cannot create identities or renew 10G/landmark verification. Archive and extracted SHA-256 are pinned in `backend/ai/models.json`; 2.5G remains for comparison. InsightFace pretrained weights are available for non-commercial research (https://github.com/deepinsight/insightface/tree/master/python-package#license). No recognition/identity model from these archives is loaded.
- OpenCV VitTrack pretrained tracker: https://github.com/opencv/opencv_zoo/tree/main/models/object_tracking_vittrack and native `cv2.TrackerVit_create` from OpenCV 4.11.0. The published ONNX model, source revision and SHA-256 are pinned in `backend/ai/models.json`; no randomly initialized or locally trained replacement is used. Model directory license: [Apache-2.0](https://github.com/opencv/opencv_zoo/blob/main/models/object_tracking_vittrack/LICENSE).
- ONNX Runtime CPU: https://github.com/microsoft/onnxruntime (MIT); one inference thread, idle spinning disabled for the face verifier.
- CavT code/checkpoint: https://github.com/mountainai/cavt. Source commit/path pinned in backend/ai/vendor/source.json; checkpoint/config URLs and SHA-256 pinned in backend/ai/models.json. The repository's public README supplies the Google Drive checkpoint link and research citation; no separate top-level LICENSE was found, so no broader license is asserted here.

CavT reference: Ai, Xusheng; Sheng, Victor; Li, Chunhua; Yang, Han; Cui, Zhiming. Class-attention video transformer for engagement prediction. Multimedia Tools and Applications, 2024. The local inference wrapper removes the MMCV registry dependency; uses the published architecture/state_dict; strips training optimizer data; dynamically quantizes CPU Linear layers; and uses MediaPipe five-point alignment instead of the author's OpenFace preparation.

TensorFlow.js Face Landmarks Detection remains installed as a legacy adapter. Source/license: https://github.com/tensorflow/tfjs-models/tree/master/face-landmarks-detection (Apache-2.0). The official portrait test fixture comes from https://github.com/tensorflow/tfjs-models/blob/master/face-landmarks-detection/test_data/portrait.jpg (Copyright 2021 Google LLC). It is used in automated checks and synthetic repeated-face benchmarks, not as evidence of classroom behavior accuracy.

Motion for React (https://github.com/motiondivision/motion, MIT) and native SVG render the annotations. Konva/react-konva and JSFeat have been removed from frontend dependencies; custom KCF/LK scale estimation is replaced by native pretrained VitTrack. React, Vite, Express, PyTorch, NumPy, einops, and other dependencies retain their upstream notices and terms in their packages.

The two-face regression JPEGs in `backend/test-fixtures/faces` additionally use
derived side-view frames from the Audio-Visual Lombard Grid Speech corpus
(https://spandh.dcs.shef.ac.uk/avlombard/), Najwa Alghamdi, Steve Maddock, Ricard
Marxer, Jon Barker and Guy J. Brown, CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/). Extraction, cropping, resizing and
composition are documented in that folder's README. Additional public frontal/profile video samples and their checksums are documented in `backend/test-fixtures/tracking/README.md`. These synthetic tests do
not establish classroom recognition/behavior accuracy.

When a compatible local Python is missing, the requirement installer downloads the pinned CPython 3.11.14 build from Astral python-build-standalone (https://github.com/astral-sh/python-build-standalone/releases/tag/20251014). Archive size and SHA-256 are in requirement.json. The distribution's CPython/third-party license files remain in .runtime/cpython-3.11.14; the installer does not change system Python or PATH.

The six application cues are temporal rules over visible measurements. The interface labels do not measure a person's internal attention or identify their real identity. Validation limits are documented in docs/AI_KIEM_CHUNG.md.

MobileViCLIP-Tiny is an optional experimental action branch, from MCG-NJU/MobileViCLIP, revision 3706de2e69d30be05c08f8fb8a4ba0619f76ea43 (MIT code). Original sources and license are retained in backend/ai/vendor/mobileviclip. Its frozen text encoder comes from Apple's MobileCLIP-S0 checkpoint; Apple code/model terms are retained under that directory's apple/LICENSE and apple/LICENSE_MODELS. Weight sources, sizes and SHA-256 are pinned in backend/ai/action_model.json. Inference-only adapters remove unused training/CUDA imports and disable gradient checkpointing; no weights are trained. The resulting model has not been fine-tuned or validated to 85% on SAV. SAV label/download sources: https://github.com/Ritatanz/SAV; no SAV videos are redistributed by this repository without actual source files.

SCB classroom research: official dataset/model source https://github.com/Whiffe/SCB-dataset and its linked Hugging Face repository https://huggingface.co/datasets/wintonYF/SCB-Dataset, revision 0fdc46fe393d251320def8c6d10cbc95d89f7da6. The downloaded model is the three-class SCB5 hand-raising/read/write YOLOv7 checkpoint, not the six-class SCB3 checkpoint. It and the sampled validation images are restricted to the upstream academic/personal/non-commercial scope; no broader rights are asserted. Model/checkpoint pins are in backend/ai/scb_model.json. Raw models and datasets are ignored by Git. YOLOv7 inference architecture comes from https://github.com/WongKinYiu/yolov7, revision a207844b1ce82d204ab36d87d496728d3d2348e7; its GPL-3.0 license remains in backend/ai/vendor/yolov7/LICENSE.md. No weights were trained locally, and the SCB branch has not passed the requested 85% verification.

An additional community classroom YOLOv8n checkpoint from https://github.com/rukeshsg/AI-Smart-Classroom-Monitoring-System, revision 5ee923f92a6ac04bd3e83566e87567d771b2a8f8, has SHA-256 64057cc20aad3cce9016d6cedea3a2d760f7d76325a6d99e72f795003fa1a76d. The upstream repository lists an MIT code license; no broader checkpoint/data rights are asserted. No upstream source was executed or included in the runtime. Earlier QA did not establish usable general classroom-action accuracy on fixed SCB samples. The current runtime uses only its `Sleeping` output as an auxiliary visible desk-rest posture cue, corroborated by independent YOLO11s person geometry, identity association and temporal checks; it does not diagnose sleep or infer concentration. All other output classes remain disabled. Source, checkpoint checksum and class metadata are pinned in `backend/ai/desk_rest_model.json`; `prepare_desk_rest.py` prepares the repository-local ONNX graph and verifies numerical equivalence to the checkpoint. Validation on `class_2.mp4` is a case review, not a benchmark accuracy claim.
